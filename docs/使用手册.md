# yt-dlp-go 使用手册

`yt-dlp-go` 是 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 下载引擎的 Go 实现，
目标是复刻其核心架构与常用功能：格式选择、输出模板、HTTP/HLS/DASH 下载、
ffmpeg 后处理、字幕、播放列表、并发下载，以及一组精选站点提取器。

> **适用范围**
> 本文档面向使用者，介绍命令参数、支持平台与示例。
> 架构与开发说明见项目根目录 `README.md`，任务进度见 `PLAN.md`。

## 1. 编译与安装

需要 **Go 1.25+**。

```bash
cd yt-dlp-go
go build -o yt-dlp-go .                 # 标准库构建（默认）
```

可选：带真实 TLS 指纹伪装的构建：

```bash
go build -tags utls -o yt-dlp-go-utls . # Chrome/Firefox/Safari/Edge 客户端指纹
```

如果 Go 官方代理不可达，可改用镜像：

```bash
GOPROXY=https://goproxy.cn,direct GOSUMDB=off go build -o yt-dlp-go .
```

### ffmpeg 依赖

以下功能需要系统已安装并在 `PATH` 中的 `ffmpeg` / `ffprobe`：

- 合并分离的视频流与音频流（`bestvideo+bestaudio`）
- 提取音频 `-x`
- 容器重封装 `--remux-video`
- 嵌入元数据、章节、字幕、缩略图
- **红果短剧 CENC 解密**

若 `ffmpeg` 不在 `PATH` 中，可用 `--ffmpeg-location` 指定其路径或所在目录。

### 红果短剧专用环境变量

下载红果短剧时，可用以下环境变量提供稳定的 19 位数字设备身份：

```bash
export DUANJU_DEVICE_ID=5938271046582391746
export DUANJU_INSTALL_ID=6745102938476510293
```

未设置时会自动为本次进程随机生成一组设备 ID，通常不影响下载。

## 2. 基本用法

```bash
yt-dlp-go [选项] URL [URL...]
```

最少用法：下载一个视频到当前目录。

```bash
./yt-dlp-go "https://www.youtube.com/watch?v=VIDEO_ID"
```

多个 URL 会并发下载：

```bash
./yt-dlp-go URL1 URL2 URL3
```

只模拟、不下载（查看解析到的标题、格式等信息）：

```bash
./yt-dlp-go -s "https://youtu.be/VIDEO_ID"
```

打印帮助：

```bash
./yt-dlp-go --help
```

## 3. 支持的站点与各自用法

当前内置提取器如下，URL 匹配到第一个支持的提取器即生效。

### 3.1 YouTube

支持网页播放页、短链 `youtu.be`、频道/播放列表页。

```bash
# 默认最佳画质
./yt-dlp-go "https://www.youtube.com/watch?v=VIDEO_ID"

# 分离视频+音频并合并
./yt-dlp-go -f "bestvideo+bestaudio" "URL"

# 指定分辨率
./yt-dlp-go -f "best[height<=720]" "URL"

# 仅模拟
./yt-dlp-go -s "URL"

# 导出信息 JSON
./yt-dlp-go -j "URL"
```

说明：

- 流地址来自 InnerTube player API，优先使用 `visionos → android_vr → web` 客户端，
  通常无需 cookies。
- 公开视频一般不需要登录 cookies；若提示 cookies 失效，可忽略，除非需要受限内容。
- 直播会走 HLS 分片下载。

### 3.2 Bilibili

支持 `BV` 视频页、合集/分 P 视频。

```bash
./yt-dlp-go "https://www.bilibili.com/video/BV1xx411c7XD"
```

说明：

- 未登录时 B 站通常只给 720p；提供登录后的 `SESSDATA` cookie 可解锁更高画质：

  ```bash
  ./yt-dlp-go --cookies bilibili_cookies.txt "URL"
  ```

- 属于 UGC 合集/季节的视频会展开为整季播放列表，可用 `--playlist-items` 选择分 P。

### 3.3 TikTok

```bash
./yt-dlp-go "https://www.tiktok.com/@user/video/123"
```

### 3.4 Douyin 抖音

```bash
./yt-dlp-go "https://www.douyin.com/video/VIDEO_ID"
```

说明：

- 优先下载无水印播放流；无水印流不可用时回退到带水印 `download_addr`。

### 3.5 红果短剧

支持以下输入形式：

```text
https://novelquickapp.com/s/<短码>/
https://hongguoduanju.com/detail?series_id=<id>
https://hongguoduanju.com/player/<series_id>
https://hongguoduanju.com/player/<series_id>/<vid>
hongguo:<video_id>
```

示例：

```bash
# 短链：自动展开、解析整部剧、下载第 1 集
export DUANJU_DEVICE_ID=5938271046582391746
export DUANJU_INSTALL_ID=6745102938476510293
./yt-dlp-go --playlist-items 1 "https://novelquickapp.com/s/OyZtu4aCveY/"

# 下载全集                                                                                       
./yt-dlp-go \
  --proxy http://127.0.0.1:7897 \
  -P "./hongguo" \
  -o "%(playlist_index)03d_%(id)s.%(ext)s" \
  "https://novelquickapp.com/s/OyZtu4aCveY/"      

# 下载整部剧前 5 集
./yt-dlp-go --playlist-items 1-5 "https://novelquickapp.com/s/OyZtu4aCveY/"

# 用 video_id 直接下载
./yt-dlp-go "hongguo:7671213206915779646"

# detail 页整部剧
./yt-dlp-go "https://hongguoduanju.com/detail?series_id=7671213206915779646"
```

说明：

- 短链只跟随首个重定向，从中读取 `zlink` / `schemeParams` 得到目标 `video_id`。
- 整部剧的 `vid_list` 会精确限定到目标 `series_id`，避免误选推荐位。
- 内部自动探测 fqnovel 类型码 `1004 / 1001 / 0 / 1 / 2 / 19`。
- 视频为 CENC 加密 MP4，下载后由 ffmpeg 自动解密；解密使用首帧可解码检测，
  已解密文件重跑会安全跳过。
- 需要 ffmpeg。

### 3.6 Acast

```bash
./yt-dlp-go -j "https://shows.acast.com/example/episodes/abc"
```

### 3.7 直链兜底

若 URL 直接指向媒体文件（如 `.mp4`、`.m3u8`、`.mpd`），会走通用提取器直接下载。

```bash
./yt-dlp-go "https://example.com/path/video.mp4"
./yt-dlp-go "https://example.com/path/playlist.m3u8"
```

## 4. 命令参数详解

### 4.1 格式选择

| 参数 | 说明 |
| --- | --- |
| `-f, --format FMT` | 格式选择器。默认 `best`。 |
| `-S, --format-sort KEYS` | 多键排序，如 `res,fps,tbr,size,proto,codec:vp9.2`。 |

`-f` 语法：

- `best` / `worst`：综合最佳 / 最差
- `bestvideo` / `bestaudio`：最佳纯视频 / 纯音频
- `bestvideo+bestaudio`：合并视频流与音频流
- `137`：按 itag 选择
- `137-140`：itag 区间
- `best[height<=720]`：过滤条件
- `best[ext=mp4]` / `best[protocol!=http]`：扩展名 / 协议过滤
- `a/b/c`：多个输出，逗号分隔
- `x/y/z`：斜杠为回退，前面失败则尝试下一个

示例：

```bash
./yt-dlp-go -f best "URL"
./yt-dlp-go -f "bestvideo+bestaudio" "URL"
./yt-dlp-go -f "best[height<=1080]" "URL"
./yt-dlp-go -S res,fps -f best "URL"
```

### 4.2 输出路径与文件名

| 参数 | 说明 |
| --- | --- |
| `-o, --output TEMPLATE` | 输出文件名模板 |
| `-P, --paths DIR` | 输出基础目录 |

可用模板字段（`%(field)s`）：

- `%(title)s`：标题
- `%(id)s`：视频 ID
- `%(ext)s`：扩展名
- `%(duration)s`：时长（秒）
- `%(upload_date)s`：上传日期 `YYYYMMDD`
- `%(playlist_index)s`：播放列表序号（1 基）
- `%(webpage_url)s`：原始页面 URL
- 默认值：`%(title|id)s` 表示标题为空时退回 ID
- 大小写转换：`%(title)l` 转小写
- 日期格式化：`%(upload_date>%Y-%m-%d)s`
- 时长格式化：`%(duration>%H:%M:%S)s`
- 字面 `%` 写作 `%%`

未指定 `-o` 时，默认使用标题或 ID 作为文件名，并做文件系统安全处理。

示例：

```bash
./yt-dlp-go -o "%(title)s.%(ext)s" "URL"
./yt-dlp-go -P "./downloads" -o "%(upload_date>%Y-%m-%d)s_%(title)s.%(ext)s" "URL"
./yt-dlp-go -o "%(playlist_index)03d_%(id)s.%(ext)s" "URL"
```

### 4.3 合并与容器

| 参数 | 说明 |
| --- | --- |
| `--merge-output-format FMT` | 合并输出容器，如 `mkv` / `mp4` |
| `--remux-video FMT` | 将视频重封装到指定容器，如 `mp4` / `mkv` |

```bash
./yt-dlp-go -f "bestvideo+bestaudio" --merge-output-format mkv "URL"
./yt-dlp-go --remux-video mp4 "URL"
```

### 4.4 网络与请求

| 参数 | 说明 |
| --- | --- |
| `--proxy URL` | HTTP/HTTPS/SOCKS5 代理，如 `http://127.0.0.1:7897` |
| `--cookies FILE` | Netscape/Mozilla 格式 cookies.txt |
| `--no-check-certificates` | 忽略 TLS 证书错误 |
| `--user-agent UA` | 自定义 User-Agent |
| `--impersonate BROWSER` | 伪装浏览器：`chrome` / `firefox` / `safari` / `edge` |
| `-R, --retries N` | 重试次数，默认 10 |
| `--socket-timeout SECS` | 连接超时时间 |
| `-r, --limit-rate RATE` | 限速，如 `50K`、`1M` |
| `-H, --add-header K:V` | 附加 HTTP 头，可重复 |
| `-u, --username USER` | 账号用户名 |
| `-p, --password PASS` | 账号密码 |
| `--netrc` | 使用 `.netrc` 凭证 |

示例：

```bash
./yt-dlp-go --proxy http://127.0.0.1:7897 "URL"
./yt-dlp-go --cookies cookies.txt "URL"
./yt-dlp-go --impersonate chrome "URL"
./yt-dlp-go -R 5 -r 1M "URL"
./yt-dlp-go -H "Referer: https://example.com" "URL"
```

> 红果短剧下载如遇到间歇性 403，可增加重试：`--retries 10`，
> 并使用 `--proxy` 走可用网络。断点续传会跳过已完成文件。

### 4.5 下载行为

| 参数 | 说明 |
| --- | --- |
| `--concurrent-fragments N` | 并发分片下载数 |
| `--skip-download` | 不下载，仅解析 |
| `-s, --simulate` | 仅模拟，不下载 |
| `--no-overwrite` | 已存在文件则跳过 |
| `--continue` | 断点续传，默认开启 |
| `--download-archive FILE` | 记录已下载 ID，后续跳过 |
| `--playlist-items SPEC` | 播放列表切片，如 `1-5,8` |
| `--no-playlist` | 只下载播放列表第一个条目 |
| `--yes-playlist` | 强制下载播放列表 |
| `--dateafter YYYYMMDD` | 只下载该日期及之后上传的 |
| `--datebefore YYYYMMDD` | 只下载该日期及之前上传的 |

示例：

```bash
./yt-dlp-go --playlist-items 1-3 "PLAYLIST_URL"
./yt-dlp-go --playlist-items 1,3,5 "PLAYLIST_URL"
./yt-dlp-go --no-playlist "URL"
./yt-dlp-go --download-archive downloaded.txt "PLAYLIST_URL"
./yt-dlp-go --concurrent-fragments 8 "URL.m3u8"
```

### 4.6 字幕

| 参数 | 说明 |
| --- | --- |
| `--write-subs` / `-w` | 下载字幕文件 |
| `--write-auto-subs` | 下载自动生成字幕 |
| `--sub-langs LANGS` | 字幕语言，如 `en,zh-Hans,all` |
| `--convert-subs FMT` | 字幕格式转换，如 `srt` / `vtt` / `ass` |

```bash
./yt-dlp-go --write-subs --sub-langs en,zh-Hans "URL"
./yt-dlp-go --write-auto-subs --sub-langs all --convert-subs srt "URL"
```

### 4.7 后处理：音频、元数据、章节

| 参数 | 说明 |
| --- | --- |
| `-x, --extract-audio` | 仅提取音频 |
| `--audio-format FMT` | 音频格式：`mp3` / `aac` / `m4a` / `opus` / `flac` / `wav` |
| `--audio-quality Q` | 音频质量，如 `320` 或 `5` |
| `--embed-metadata` | 嵌入元数据：标题/上传者/日期/描述/统计 |
| `--embed-chapters` | 嵌入章节标记 |
| `--write-thumbnail` | 保存封面图 |
| `--write-description` | 保存视频描述 |
| `--write-info-json` | 写入 `.info.json` |
| `--trim-filenames N` | 限制文件名长度 |
| `--no-colors` | 关闭彩色输出 |

示例：

```bash
./yt-dlp-go -x --audio-format mp3 "URL"
./yt-dlp-go -x --audio-format m4a --audio-quality 320 "URL"
./yt-dlp-go --embed-metadata --write-thumbnail "URL"
./yt-dlp-go --embed-chapters "URL"
```

### 4.8 SponsorBlock

| 参数 | 说明 |
| --- | --- |
| `--sponsorblock-mark` | 将 SponsorBlock 片段标记为章节 |
| `--sponsorblock-remove` | 从视频中裁剪 SponsorBlock 片段 |
| `--sponsorblock-categories CATS` | 作用分类，逗号分隔，默认 `sponsor` |

```bash
./yt-dlp-go --sponsorblock-mark "URL"
./yt-dlp-go --sponsorblock-remove --sponsorblock-categories sponsor,intro "URL"
```

### 4.9 输出与调试

| 参数 | 说明 |
| --- | --- |
| `--print FIELD` | 打印模板字段，如 `%(title)s` |
| `-j, --dump-json` | 向 stdout 输出信息 JSON |
| `-v, --verbose` | 详细日志 |
| `-q, --quiet` | 安静模式 |
| `--no-warnings` | 忽略警告 |
| `--ffmpeg-location PATH` | ffmpeg/ffprobe 路径 |
| `--version` | 打印版本 |
| `-h, --help` | 显示帮助 |

```bash
./yt-dlp-go --print "%(title)s" "URL"
./yt-dlp-go -j "URL"
./yt-dlp-go -v "URL"
```

## 6. 常见问题

**Q：提示需要 ffmpeg？**
A：合并、提取音频、重封装、嵌入元数据、红果解密都需要 ffmpeg。
安装后加入 `PATH`，或用 `--ffmpeg-location` 指定。

**Q：红果短剧下载失败或 403？**
A：红果 CDN 可能间歇性返回 403/302，重试通常可成功。
建议 `--retries 10`，必要时加 `--proxy`。已下载文件重跑会自动跳过。

**Q：Bilibili 只有 720p？**
A：未登录默认 720p。提供登录 `SESSDATA` cookie 可解锁更高画质。

**Q：YouTube 需要 cookies 吗？**
A：公开视频一般不需要。受限内容可能需要有效 cookies。

**Q：支持哪些播放列表？**
A：支持 `--playlist-items` 切片、`--no-playlist` 只取首条、
`--download-archive` 跳过已下载。红果整部剧也会作为播放列表处理。

**Q：输出文件名里有非法字符？**
A：模板渲染后会自动做文件系统安全处理；可用 `%(title|id)s` 在标题为空时退回 ID。
